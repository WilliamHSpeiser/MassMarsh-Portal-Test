Test sites for the Restoration Efficacy Report upload (beta), 21 Oct 2026: nine Great Marsh features (two small and two large polygons, two lines, three points) as GeoJSON in WGS84, UTM 19N NAD83 (EPSG:26919), Massachusetts State Plane Mainland metres (EPSG:26986) and US feet (EPSG:2249), Web Mercator without a crs member (tests the number-range detection), and as zipped and loose shapefiles (one layer per geometry type). Point site 3 sits on the barrier beach where the pixel cube has no marsh pixels, so it is expected to report no data.

great_marsh_test_sites.gpkg (21 Oct 2026): the same nine features as a GeoPackage with four layers: great_marsh_points, great_marsh_lines and great_marsh_polygons in UTM 19N NAD83 (EPSG:26919) plus points_wgs84_copy (the three points again in longitude / latitude), so one file mixes two coordinate systems. Both the Restoration Efficacy Report upload windows and the Data Viewer's Add File read it (every feature table in the file, converted with the spatial reference stored in the file).
